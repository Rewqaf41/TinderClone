# mello — ближе, чем кажется

Презентационное frontend-приложение знакомств: минималистичный тёмный интерфейс для телефона, локальные фотографии и анимации Anime.js 4.5. React 19, TypeScript, Vite, React Router, Tailwind CSS 4, Lucide.

## Запуск

```bash
bun install
bun run dev
```

Приложение доступно на http://localhost:3000. Также можно использовать npm install / npm run dev.

## Что работает

- Анкеты с фотографиями, описанием и общими интересами.
- Свайпы мышью и касанием, лайк, пропуск, суперлайк, возврат последней анкеты. Стрелки клавиатуры работают вне полей ввода и модальных окон.
- Фильтры по возрасту, расстоянию и онлайн-статусу; пустое состояние и повторный просмотр.
- Взаимные и отправленные симпатии, экран мэтча, переход в диалог.
- Переписки с поиском, отправкой и локальным сохранением сообщений.
- Редактирование имени, возраста, описания, интересов и загрузка фото. Изображения уменьшаются перед сохранением.
- Настройки, уведомления, советы и сброс демо.
- Мобильная навигация, доступные диалоги с Escape и удержанием фокуса, поддержка reduced motion.

## Сценарий показа

Открой главную → поставь лайк Анне → откроется взаимная симпатия → нажми «Начать общение» → отправь сообщение. Затем покажи профиль, редактирование, фильтры на телефоне. Сбросить изменения можно в настройках.

Это демо без сервера, регистрации и реальных пользователей. Все анкеты и диалоги вымышлены; мэтчи с Анной, Алисой и Катей смоделированы. Данные сохраняются в localStorage (`mello-demo-v1`). Сообщения не отправляются другим людям. Москва — фиксированный город демо; геолокация не запрашивается.

## Проверки

```bash
bun run build
bun run lint
bun run test:e2e
```

E2E-тесты запускаются в установленном Google Chrome. Проверяют свайп → мэтч → чат, сохранение переписки и профиля, возврат анкеты, фильтры, фотографии, мобильную навигацию и отсутствие горизонтального скролла. Снимки экрана появляются в игнорируемой папке `test-results`.

## Код

Новый интерфейс: `src/features/dating/ui`. Типы, демо-данные и сохранение: `src/features/dating/model`. Оболочка и маршруты: `src/app/App.tsx`. Общие стили: `src/app/styles/index.css`. Исходные модули тестового задания оставлены в проекте для последующей интеграции с API, Framer Motion удалён из зависимостей и импортов.

Фотографии Unsplash сохранены в `public/images`, чтобы демонстрация не зависела от стороннего сервиса. Это иллюстрации вымышленных анкет, а не реальные пользователи. Источники: [исходное фото Анны](https://images.unsplash.com/photo-1494790108377-be9c29b29330), [каталог Unsplash](https://unsplash.com). Для использования в публичном коммерческом сервисе замените демонстрационные анкеты пользовательским контентом.

Для публикации собери `dist` и настрой SPA fallback на `index.html` у выбранного хостинга.
